# Hebrew QA / Tech Glossary

Most common terms in Israeli QA/Automation job postings. RTL text — read right-to-left.

## Requirement markers
| Hebrew | English |
|--------|---------|
| חובה | Required / Must-have |
| יתרון | Advantage / Nice-to-have / Plus |
| חובה מוחלטת | Absolute must |
| רצוי | Preferred |
| דרישות התפקיד | Role requirements |
| תיאור התפקיד | Role description |

## Experience
| Hebrew | English |
|--------|---------|
| ניסיון | Experience |
| שנות ניסיון | Years of experience |
| ניסיון מוכח | Proven experience |
| לפחות X שנים | At least X years |
| ידע ב- | Knowledge of |
| היכרות עם | Familiarity with |
| יכולת | Ability |
